# Mesh view build (M1, #440)

Criterion micro-benchmark `mesh_view` of `mimic-core` ([SPEC MSH-14](../SPEC.md#1221-m1--mimicconfig-and-the-mesh-view-440)):
`mesh::view::build` for one deployment of a namespace with 1000 Services, one port each, 10 endpoints
per Service (10 000 endpoints in all, the default bounds), one `MimicConfig`, no cross-namespace
destination. The build includes the lookup tables, the canonical JSON and the ETag; it does not
include the conversion of watched objects into the input structs (#441).

```
cargo bench -p mimic-core --bench mesh_view
```

| Date | Machine | Load during the run | Time per view (criterion, 95 % interval) |
|---|---|---|---|
| 2026-11-12 | Intel i7-8750H @ 2.20 GHz, 12 threads, rustc 1.99.1, release profile | **not quiet**: load average 14 to 20 (other builds and tests of other agents on the same machine) | 14.7 ms, 15.0 ms, 15.4 ms (low, estimate, high) |

The number is an upper bound of what a quiet machine gives and only fixes an order of magnitude: a full
rebuild of the largest allowed view costs about 15 ms, well under the 1 s debounce ceiling of design §4.3.
No budget is set yet; a quiet-machine run replaces this row when the controller milestone (#441) measures
the whole path.
