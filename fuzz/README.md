# Fuzzing

[cargo-fuzz](https://github.com/rust-fuzz/cargo-fuzz) targets for the parsers that read
untrusted input. This directory is its own Cargo workspace, excluded from the root one:
`cargo test --workspace` does not build it.

## Setup

```sh
rustup toolchain install nightly --profile minimal
cargo install cargo-fuzz
```

## Run

From `fuzz/`:

```sh
cargo +nightly fuzz build                      # every target
cargo +nightly fuzz run tls_sni corpus/tls_sni seeds/tls_sni -- -max_total_time=60
```

Pass `corpus/<target>` first: libFuzzer writes the new inputs it finds into the first
directory (`corpus/` is git-ignored), and only reads the committed seeds in `seeds/<target>`.
Crashes land in `artifacts/<target>/`; replay one with
`cargo +nightly fuzz run <target> artifacts/<target>/crash-…`.

Useful libFuzzer flags: `-max_total_time=<s>`, `-rss_limit_mb=2048`, `-malloc_limit_mb=1024`
(catches a single oversized allocation; `64` holds for `capture_decode` and `mock_form`), `-jobs=<n>`.

## Targets and invariants

Each target asserts properties, not just the absence of panics.

| Target | Parser | Invariants |
|---|---|---|
| `net_classify` | `mimic_proxy::net::classify` (core of `net::detect`) | Undecided only on an empty or ambiguous HTTP start (< 12 bytes, not `0x16`); a decision never changes when more bytes arrive. |
| `tls_sni` | `mimic_proxy::tls::parse_sni` | `None`, or a lowercase host name of 1 to 255 bytes that forms a valid `host:port` authority whose host is exactly the name (no `/`, `@`, `\0`). |
| `redact_json` | `mimic_core::redact` on JSON bodies | Idempotent; a secret injected under a sensitive key, query parameter and header never survives in the exchange; an unparseable body (10 000 nested `[`) is dropped without stack overflow. Same for the mock-side request when the body parses. |
| `redact_form` | `mimic_core::redact` on form bodies | Idempotent; a secret injected as `client_secret` and `password` never survives, on the exchange and on the mock-side request. |
| `capture_decode` | `capture::decode` (gzip, deflate, br, zstd) | Output ≤ `limit` (decompression bombs stop at the bound); decoded output re-encodes and decodes to the same bytes. Input: 1 encoding byte, 3 bytes of limit (≤ 1 MiB), body. |
| `inject_annotations` | `mimic_injector::inject::mutate` (annotation checks) | The `mimic-init` variables (container env or CNI annotation) re-parse in `mimic-init` / `mimic-cni` and are canonical (no whitespace, so no `-j ACCEPT` smuggling); `MIMIC_LOG` is a valid filter; mutation is deterministic and idempotent on re-invocation. Input: lines `flags` (`c` CNI, `i` inbound), inbound ports, excluded CIDRs, excluded ports, log filter. |
| `cni_settings` | `mimic_cni::settings` | Unknown keys are refused; `MIMIC_IPTABLES` is only one of the three allowed binaries; a valid annotation is accepted and its values are kept as is. |
| `segments` | `Snapshot::parse` (controller segment ingestion, snapshot import), `Exemplars::parse` | Error, never panic; accepted content round-trips through its canonical form under the same id; redaction is idempotent; the mock form built from it reads back identically. |
| `mock_form` | Sidecar mock-form decoding (`decode` + `MockSnapshot::from_json` + `MockEngine`) | Decompression bounded; error, never panic; accepted forms round-trip; the engine answers requests built from its records. |

`capture::decode` is private: the `mimic_proxy::fuzzing` module re-exports it only when
compiled with `--cfg fuzzing` (set by cargo-fuzz), so normal builds keep the same public API.

## Seeds

`seeds/` is generated by `cargo run --example seeds` (deterministic except the rustls
ClientHello, whose random and key share change on each run; the stable toolchain is
enough). It holds valid inputs taken from the unit tests and known hostile inputs: a
ClientHello truncated at every offset, an SNI length larger than the record, SNIs holding
`\0`, `/` or `@`; gzip, brotli and zstd bombs (DEFLATE caps at about 1000:1, so the gzip
bomb is 1 KiB → 1 MiB; the brotli and zstd ones expand to 1 GiB), a brotli stream with a
bad window, zstd frames announcing a 128 MiB and 2 GiB window; 10 000 nested `[`;
annotation values with `,,`, port 65536, CIDR `/33` and `-j ACCEPT`; CNI annotations with
unknown keys and `MIMIC_IPTABLES=/bin/sh`.

A crash fixed in the code keeps its input as a regular unit test next to the parser.
